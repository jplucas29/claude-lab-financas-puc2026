# Scripts

`baixar_dados_bcb.py` baixa (ou atualiza) os dados dos Cases 1 e 2 direto das APIs públicas do Banco Central:

```bash
pip install requests pandas
python scripts/baixar_dados_bcb.py
```

É um bom ponto de partida para o **caminho avançado**: transformar esse download num fluxo que roda sozinho toda semana e já entrega a análise pronta.
